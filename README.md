# Website Eira Trans

Landing page statis untuk Eira Trans, layanan travel rute Brebes - Jakarta.

## File utama

- `index.html` — struktur halaman landing page.
- `styles.css` — styling responsif halaman.
- `hero.webp` — aset hero untuk bagian pembuka website.

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
python -m http.server 8000
```

Lalu kunjungi `http://localhost:8000`.
